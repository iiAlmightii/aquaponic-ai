# Experiential Learning (EL) - Point 3 Submission

## EL Requirement Addressed
Create Project plan with clear objectives for the major project in the 4th semester using tools like Jira or Smartsheet.

Project: Aquaponic AI Platform (major project)
Course: Project Management (MCA293E4)

## Project Objective Statement
Build and validate an AI-assisted aquaponic decision-support platform that:
- collects farm/survey and optional IoT inputs,
- generates financial feasibility outputs (CAPEX/OPEX/ROI/NPV/IRR scenarios),
- provides advisory/reporting workflows through a web application,
- supports clear documentation, testing, and deployable architecture.

## Scope Included in Plan
- Backend APIs (FastAPI), services, and financial engine
- Frontend user workflows (survey, dashboard, reports)
- Authentication and session flow
- Data persistence and infra setup (PostgreSQL/Redis/Docker)
- Testing, documentation, and EL submission readiness
